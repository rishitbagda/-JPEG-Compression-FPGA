# Image sources

The astronaut image is the scikit-image `astronaut` sample, showing Eileen Collins, originally from NASA. The scikit-image documentation identifies it as public domain with no known copyright restrictions.

- Documentation and rights statement: https://scikit-image.org/docs/stable/api/skimage.data.html
- Retrieved image: https://raw.githubusercontent.com/scikit-image/scikit-image/v0.17.2/skimage/data/astronaut.png
- Original photograph as included: `examples/input/astronaut-original-512x512.png`
- Processing: cropped to 512 x 448, resized with Pillow LANCZOS to 320 x 280, then encoded by this project's RTL.

The color artwork and grayscale photograph are the demonstration images supplied with the team's project. Their encoded examples were verified against the provided RTL during repository organization.
